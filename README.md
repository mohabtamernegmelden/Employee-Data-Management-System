Employee Data Management System
Project Description

The Employee Data Management System is a Python-based command-line application designed to manage employee records efficiently. The system allows users to add, view, update, search, and delete employee information using a structured and user-friendly interface.

The project is built around a single class, EmployeeManager, which handles all employee-related operations and data storage. Employee records are stored using Python dictionaries and lists, and persistent data storage is achieved through CSV file handling using Python’s built-in csv module.

This project demonstrates practical usage of core Python concepts such as data structures, file handling, functions, conditional logic, and basic CLI design. It is ideal for understanding how small-scale management systems work and how Python can be used to build real-world applications.
